# Домашнее задание lab08

Лабораторная работа Лисейчиковой Екатерины

## Что требовалось сделать

Домашнее задание относится к теме лабораторной работы VIII: изучение автоматизации развертывания на примере docker.

## Выполненные пункты

- контейнер собирает проект внутри Linux-окружения, независимо от системы разработчика;
- логи не теряются после завершения контейнера, потому что пишутся в volume;
- переменная `LOG_PATH` задана в Dockerfile и может переопределяться в compose;
- CI может проверять Docker-сборку командой `docker build`.

## Как проверить домашнее задание

```bash
docker build -t formatter-logger .
mkdir -p logs
docker run -i -v "$(pwd)/logs:/home/logs" formatter-logger
cat logs/log.txt
docker compose run --rm logger
```

## Пояснение по реализации

Проект оформлен так, чтобы его можно было перенести в Linux-окружение и собрать стандартными командами CMake. Файлы не завязаны на абсолютные пути macOS, персональные секреты не добавлены в git, а дополнительные инструменты подключаются через конфигурационные файлы конкретной лабораторной.
