# lab08

Лабораторная работа Лисейчиковой Екатерины

## Отчет по лабораторной работе VIII

### Тема

Изучение автоматизации развертывания на примере Docker.

### Цель работы

Цель работы - упаковать demo-приложение в Docker-образ и описать запуск с volume для логов.

### Используемое окружение

- основной целевой сценарий: Linux;
- язык: C++11;
- система сборки: CMake;
- дополнительные инструменты добавляются по теме конкретной лабораторной;
- персональные токены и временные адреса не сохраняются в репозитории.

### Структура проекта

- `formatter_lib` - базовая статическая библиотека форматирования;
- `formatter_ex_lib` - расширенная библиотека, использующая `formatter`;
- `solver_lib` - библиотека для решения квадратного уравнения;
- `hello_world_application` - демонстрационное приложение;
- `solver_application` - приложение для вывода корней уравнения;
- `tests` - модульные тесты, начиная с lab05;
- `docs` и `scripts` - дополнительные материалы поздних лабораторных.

### Ход выполнения

- добавлен `Dockerfile` на базе `ubuntu:22.04`; 
- в контейнере устанавливаются `cmake`, `g++` и `make`; 
- проект копируется в `/opt/formatter-workspace`, собирается и устанавливается;
- entrypoint запускает установленное приложение `demo`; 
- добавлен `docker-compose.yml` с volume `./logs:/home/logs`.

### Команды для проверки

```bash
docker build -t formatter-logger .
mkdir -p logs
docker run -i -v "$(pwd)/logs:/home/logs" formatter-logger
cat logs/log.txt
docker compose run --rm logger
```

### Домашнее задание

Домашнее задание выполнено внутри этого же репозитория. Подробное описание вынесено в `HOMEWORK.md`.

Кратко по выполнению:

- контейнер собирает проект внутри Linux-окружения, независимо от системы разработчика;
- логи не теряются после завершения контейнера, потому что пишутся в volume;
- переменная `LOG_PATH` задана в Dockerfile и может переопределяться в compose;
- CI может проверять Docker-сборку командой `docker build`.

### Результат

Приложение можно запускать одинаково на любой машине с Docker, а результат работы сохраняется на хосте.
